INSTALL WINDOWS 11
BY : SWEATER PINK
TUTORIAL INSTALL WINDOWS 11
⚠️ PERINGATAN

Clean install dapat menghapus data pada drive yang dipilih. Backup semua file penting sebelum memulai.
1. PERSIAPKAN

☐ Backup semua file penting.
☐ Flashdisk minimal 8 GB — disarankan 16 GB.
☐ File Windows 11 ISO.
☐ Aplikasi Rufus.
☐ Internet untuk download/update.
☐ PC/laptop tersambung listrik.
2. BUAT USB WINDOWS 11 DENGAN RUFUS

Buka Rufus setelah flashdisk terpasang.

Device → pilih flashdisk.
Boot selection → Disk or ISO image.
Klik SELECT → pilih Windows 11 ISO.
Image option → Standard Windows 11 Installation.
Partition scheme → GPT.
Target system → UEFI.

Klik START lalu tunggu sampai status menjadi READY.
3. RESTART DAN MASUK BOOT MENU

Jangan cabut flashdisk.
Restart PC lalu tekan tombol Boot Menu berulang kali saat logo muncul.

ASUS → F8
MSI → F11
Gigabyte → F12
ASRock → F11
Dell → F12
HP → Esc / F9
Lenovo → F12
Acer → F12

Jika tidak tahu merek motherboard/laptop, cari mereknya terlebih dahulu.

Pilih: UEFI: NAMA FLASHDISK Lalu tekan Enter.
4. WINDOWS SETUP

Pilih bahasa → Indonesia.
Pilih Time/Currency → Indonesia.
Pilih Keyboard sesuai kebutuhan.

Klik Next → Install now.
5. PRODUCT KEY

Jika punya Product Key → masukkan key.

Jika tidak punya: I don't have a product key
6. PILIH EDISI WINDOWS

Pilih sesuai lisensi kamu:

Windows 11 Home
atau
Windows 11 Pro

Klik Next lalu centang persetujuan lisensi.
7. PILIH CLEAN INSTALL

Saat muncul: Which type of installation do you want? Pilih: Custom: Install Windows only (advanced) Jangan pilih Upgrade.
🔴 8. DELETE PARTISI WINDOWS LAMA

Sekarang muncul: Where do you want to install Windows? Contoh: Drive 0 Partition 1 Drive 0 Partition 2 Drive 0 Partition 3 Drive 0 Partition 4 Jika Drive 0 adalah SSD tempat Windows lama dan kamu ingin menghapus seluruh Windows lama:

Klik Partition 1 → Delete → OK.
Klik Partition 2 → Delete → OK.
Klik Partition 3 → Delete → OK.
Klik Partition 4 → Delete → OK.

Lakukan pada semua partisi di Drive 0 yang memang ingin dihapus. Pada akhirnya harus menjadi: Drive 0 Unallocated Space
🚨 JANGAN SALAH DRIVE

Kalau ada: Drive 0 Drive 1 Jangan menghapus Drive 1 jika berisi data penting. Jika tidak yakin, berhenti dan cek kembali drive yang benar sebelum menekan Delete.
🟢 9. INSTALL WINDOWS 11

Setelah menjadi: Drive 0 Unallocated Space Klik Drive 0 Unallocated Space. Kemudian klik: Next Windows akan otomatis membuat partisi yang diperlukan. Tunggu sampai instalasi selesai.
10. SAAT PC RESTART

Jika muncul: Press any key to boot from USB... JANGAN tekan tombol apa pun.

Biarkan komputer boot dari SSD. Jika kembali ke installer dari awal, cabut flashdisk lalu restart PC.
🟢 11. SETUP WINDOWS 11

Pilih negara → Indonesia.
Pilih keyboard → sesuai kebutuhan.
Keyboard kedua → Skip jika tidak diperlukan.

Lanjutkan setup sampai bagian koneksi internet.
🔴 12. LEWATI AKUN MICROSOFT

Jika Windows meminta akun Microsoft: Tekan: Shift + F10 Command Prompt akan muncul. Ketik: OOBE\BYPASSNRO Kemudian tekan Enter. PC akan restart. Setelah kembali ke setup:

I don't have internet
↓
Continue with limited setup

Kemudian buat username lokal dan password jika diperlukan.
🟡 13. JIKA OOBE\BYPASSNRO ERROR

Jika perintah tidak dikenali atau tidak bekerja, coba: Shift + F10 start ms-cxh:localonly Kemudian tekan Enter. Jika build Windows mendukungnya, akan muncul pilihan untuk membuat akun lokal.
🟡 ALTERNATIF: GUNAKAN RUFUS

Jika USB belum dibuat, saat Rufus menjalankan proses START, perhatikan bagian: Windows User Experience Jika tersedia, gunakan opsi seperti: Remove requirement for an online Microsoft account Create a local account Nama opsi dapat berbeda tergantung versi Rufus.
🟢 14. SETELAH MASUK DESKTOP

Buka: Settings → Windows Update Klik Check for updates. Install semua update kemudian restart. Check for updates lagi sampai tidak ada update penting.
🟢 15. INSTALL DRIVER

Buka: Start → Device Manager Pastikan tidak ada tanda: ⚠️ Unknown Device Install driver jika diperlukan:

☐ Chipset
☐ LAN
☐ Wi-Fi
☐ Bluetooth
☐ Audio
☐ GPU/VGA
🟢 16. CEK AKTIVASI

Buka: Settings → System → Activation Cek apakah Windows sudah aktif.
🟢 17. TES HARDWARE
